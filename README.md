# Simulado dos gabaritos

Simulado de estudo para as Provas Finais do MBA em Data Science e Analytics (USP/Esalq), montado com as questões dos gabaritos das avaliações do curso.

Tem um modo de prova real (P1 com 10 questões, P2 com 5, 25 minutos cada, sem correção durante), um modo de estudo com correção na hora e explicação de cada resposta, e um painel que mostra em quais áreas você está mais fraco. O desempenho de cada pessoa fica salvo só no próprio navegador.

O repositório é público: dá para copiar (fork) e adaptar como quiser, corrigir questões, mudar o visual ou acrescentar mais. Sugestões de correção podem vir por pull request.

O código tem licença MIT (arquivo LICENSE). As questões vêm das avaliações do curso e não são cobertas por essa licença.
